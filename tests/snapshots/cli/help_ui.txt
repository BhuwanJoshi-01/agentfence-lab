Usage: agentfence ui [OPTIONS]

  Serve the read-only dashboard and API on loopback.

  Needs the 'ui' extra. Prints the dashboard URL with a random session token in
  its fragment; API requests must send that token as a bearer token. Requests
  for another host name or from another origin are refused. Nothing can be
  launched or changed. Stop with Ctrl-C.

Options:
  --host <str>     Loopback address (default: ui.listen).
  --port <int>     Port (default: ui.port).
  --config <path>  Project config file (default: ./agentfence.yaml).
  --help           Show this message and exit.
